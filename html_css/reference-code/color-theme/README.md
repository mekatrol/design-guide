# Color Theme Reference

This plain HTML, CSS, and TypeScript example demonstrates the light and dark theme rules in the [HTML and CSS design guide](../../color-theme.md).

## Run

```bash
npm install
npm run dev
```

Open the URL printed by Vite, normally `http://localhost:5173`.

## Debug in VS Code

Copy the content of [`vscode/launch.json`](vscode/launch.json) into `.vscode/launch.json`, start `npm run dev` in the integrated terminal, and press `F5`.

## Format on Save in VS Code

Copy the content of [`vscode/settings.json`](vscode/settings.json) into `.vscode/settings.json` and [`vscode/extensions.json`](vscode/extensions.json) into `.vscode/extensions.json`. Install the recommended ESLint and OXC extensions when prompted.

The project is configured to apply ESLint fixes and format JavaScript, TypeScript, JSON, HTML, and CSS on save. Formatting requires semicolons, disallows trailing commas, and uses single quotes.
